# Singularity

A black hole that lives in the Windows taskbar. Alt+F4 pulls windows into it, one shortcut swallows everything at once, a white hole brings it all back, and an orbit view shows your apps circling it.

This repository only holds the Windows installers. Installed copies check here for updates and install them from Settings → About and updates.

## Download

Get **Singularity-Setup-x.y.z.exe** from the [latest release](https://github.com/Asepritez/singularity-releases/releases/latest) and run it. Windows 10 or 11.

There is also a portable `.exe` that runs without installing (it does not update itself).

Windows SmartScreen may warn that the app is unrecognised, because the installer is not code-signed: choose **More info → Run anyway**.
